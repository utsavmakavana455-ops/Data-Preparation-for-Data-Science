# Data Preparation for Data Science

## Overview

This repository contains practical Data Science tasks focused on data preparation and preprocessing. The project demonstrates essential techniques used to clean, transform, and prepare datasets for analysis and machine learning.

## Objectives

* Understand dataset structure and quality
* Identify and handle missing values
* Remove duplicate records
* Perform feature engineering
* Apply categorical encoding
* Normalize numerical features
* Prepare data for analysis and machine learning
